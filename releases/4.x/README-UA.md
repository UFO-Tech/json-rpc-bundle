# 4.x — JSON-RPC 2.0 сервер для Symfony 6

Вимоги (composer.json на 4.5.2): PHP `>=8.1`, Symfony `6.*`, `laminas/laminas-json-server >=3.2`, `ufo-tech/rpc-objects 1.*`, `ufo-tech/rpc-exceptions 1.*`.

Мажорна версія 4 — переробка пакета під PHP 8.1 і Symfony 6. Будь-який сервіс, що реалізує `IRpcService`, стає набором JSON-RPC методів на одному endpoint; пакет додає batch-запити з передачею результатів, паралельну обробку batch у консольних процесах, доставку відповідей на callback, захист токеном та експорт для SoapUI. Карта сервісів і диспетчеризація побудовані на Laminas JSON Server.

| Версія | Головне |
|---|---|
| [4.5](4.5/README-UA.md) | База: процедури `IRpcService`, карта сервісів `GET`, batch з ланцюжком `@FROM:`, паралельний batch через `ufo:rpc:process`, `$rpc.callback`, захист токеном, експорт SoapUI |
